Project / Tech

Charcoal.

Github Repo ↗

Built a full-stack, browser-based Markdown notes application as a university project at IU. Tasks, progress, and deadlines were planned and tracked in Monday.com.

GitHub Flavored Markdown covers headings, lists, tables, task lists, links, and syntax-highlighted code blocks. Titles and content auto-save as the user types. Registered users keep notes in PostgreSQL, tied to the account. Guest mode stores notes for the browser session only.

Accounts include registration, login, profile updates, logout, and deletion. Password reset uses time-limited email links, with optional email notifications. Export writes a local .md file and leaves it on the device. The layout is a notes sidebar on desktop and a drawer on mobile.

Project / Management

IT Service Management.

Designed an ITIL 4-based service management solution for a mid-sized enterprise with IT operational inefficiencies. The roadmap outsources the IT Service Desk along the ITIL 4 Customer Journey: Explore, Engage, Offer, Agree, Onboard, Co-create, Realise.

Stakeholder analysis covers the Board of Directors, Internal IT Team, External CIO, consultants, and outsourced service providers. SLA considerations and a governance model sit between internal IT and the vendor. Communication workflows, escalation, and responsibilities are defined for both sides.

Mandatory practices include Incident Management, Problem Management, Service Desk, Change Enablement, Information Security, and Continual Improvement. A risk, challenge, and opportunity assessment closes the work — aimed at service quality, governance, and customer satisfaction.
